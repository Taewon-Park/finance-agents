# 1단계 결과: 섹터 ETF 기술적 전략 4계열 비교

- 작성: 2026-11-10
- 스펙: [`stage1-spec.md`](../../stage1-spec.md)
- 코드: main `2effc11` (PR #2). 후보 파일 `config/candidates.yaml` (커밋 `e4ea7c1`)
- 수치 출처: `results/`의 `experiments.parquet`, `benchmarks.parquet`, `equity_curves.parquet`, `holdout.lock` (git 제외)
- 재현: `uv run swinglab report stage1` (리포트), `uv run python scripts/vol_matched_benchmark.py` (변동성 맞춤 벤치마크)

## 결론

- 검증 구간(2019-01-02 ~ 2026-11-06)에서 5bp 기준으로 같은 기간 SPY 바이앤홀드 샤프(0.90)를 넘은 후보는 없다.
- C(breakout 20/10)는 0.88로, 원래 기준 0.84는 넘는다. 하지만 0.84는 기간이 다른 값이라 참고용으로만 둔다.
- SPY와 현금을 섞어 변동성을 맞춘 벤치마크와 비교해도 5bp에서 CAGR이 더 높은 후보는 없다. MDD는 네 후보 모두 벤치마크보다 얕다.
- 검증 구간은 1회 실행했다 (`holdout.lock` 기록 1줄, `forced=false`). A·D는 0단계에서 검증 구간에 일부 노출됐고, B·C는 노출되지 않았다.

## 2. 검증 구간 판정 (5bp)

판정 기준은 같은 기간 SPY 바이앤홀드의 5bp 샤프 0.90이다. 원래 기준 0.84는 0단계 전체 기간(2010~2026)의 SPY 샤프다. 후보의 검증 구간(2019~2026)과 기간이 달라 참고용으로만 둔다. 기준을 바꾼 경위는 스펙의 "기준 변경 기록"에 있다.

| 후보 | 검증 샤프 | 판정 (같은 기간 SPY 0.90) | 참고: 원래 기준 0.84 |
| --- | --- | --- | --- |
| A | 0.69 | 미달 | 미달 |
| B | 0.57 | 미달 | 미달 |
| **C** | **0.88** | **같은 기간 SPY 기준 미달, 원래 기준은 기간 불일치로 참고용** | 넘음 (0.88 > 0.84) |
| D | 0.62 | 미달 | 미달 |

- 두 기준의 결론이 다른 후보는 C 하나다.
- 비용별로 보면 C는 0bp에서 0.96으로 두 값 모두 넘고, 10bp에서 0.80으로 둘 다 넘지 못한다.

## 3. 변동성 맞춤 벤치마크 (검증 구간)

후보마다 SPY와 현금(수익률 0%)을 섞어, 검증 구간 연 변동성을 후보와 같게 맞춘 포트폴리오다. 새 전략 시도가 아니므로 실험 로그와 예산에 넣지 않았다. `results/`에 저장된 검증 구간 자산곡선만 읽어 계산했고, 백테스트는 다시 돌리지 않았다.

- SPY 비중 = 후보 연 변동성 ÷ 같은 구간·같은 비용의 SPY 연 변동성. 결과를 보고 사후에 정한 비중이다.
- 매일 같은 비중으로 다시 맞춘다고 가정했고(일간 수익률 = 비중 × SPY 일간 수익률), 재조정 비용은 넣지 않았다.
- 샤프는 무위험수익률 0으로 계산한다. 그래서 벤치마크 샤프는 비중과 상관없이 SPY와 같은 0.90이다. 같은 위험에서의 비교는 CAGR과 MDD로 본다.

## 5. 재실행 경위와 검증 구간 실행 횟수

### 재실행 경위 (학습 구간만, 검증 구간 데이터 미사용)

- **첫 학습 실행** (2026-11-08, git `506d853`): 성과를 전략마다 워밍업이 끝난 날부터 집계했다. 그래서 집계 시작일이 서로 달랐다.
  - sma_cross 2010-03-31, C 2010-04-07, B(6개월) 2010-08-04, A·D 2010-10-19, B(12개월) 2011-02-02
- **문제**: D의 필터 전후 비교가 서로 다른 기간끼리의 비교가 됐다. 예를 들어 sma_cross는 필터 전이 2010-03-31부터, 필터 후가 2010-10-19부터였다. B의 lookback 6개월·12개월 비교도 마찬가지였다.
- **재실행**: 후보 선정 중에 이 문제를 발견했다. 사람 승인을 받아 A~D 전부를 공통 시작일 2011-03-01로 다시 돌렸고(2026-11-09, git `c67db83`), 선정에는 재실행 결과만 썼다. 2011-03-01은 가장 긴 워밍업(B lookback 12개월)이 끝난 뒤의 첫 월초다.
- **결과 변화**: D 후보가 sma_cross+필터(첫 실행 샤프 0.86)에서 rsi2_v2+필터로 바뀌었다. 재실행 샤프는 rsi2_v2+필터 0.80, sma_cross+필터 0.76이다. A·B·C 후보는 바뀌지 않았다.
- 같은 조합을 다시 돌린 것이라 시도 수는 15회 그대로다. 첫 실행 기록 48행은 실험 로그에 남아 있다.
- 재실행은 첫 실행의 학습 구간 결과를 본 뒤에 결정했다. 이 경위는 스펙 구간 절과 `candidates.yaml`의 `procedure_notes`에도 적혀 있다.

### 검증 구간 실행 횟수: 1회

- `results/holdout.lock`: 1줄. 2026-11-10T13:53:40Z, git `e4ea7c1`, `forced=false`, 후보 4개, 후보 해시 `dd649cc87df0…`
- 실험 로그의 검증 구간 행은 12개(후보 4개 × 비용 3개)다. 모두 같은 실행에서 기록됐다(13:53:40~43). 그 전에 기록된 검증 구간 행은 없다.
- 학습 실행 자산곡선 99개(실험 96개, SPY 3개)는 모두 2018-12-31에 끝난다. 학습 실행이 2019년 이후 데이터를 쓰지 않았다.
- 한계: lock은 `swinglab holdout` 경로로 실행한 것만 기록한다. 다른 경로로 2019년 이후 데이터를 본 것은 남지 않는다. 그런 노출은 6절에 정리했다.
- 3절의 변동성 맞춤 벤치마크는 이미 저장된 검증 구간 자산곡선을 다시 계산한 것이다. 검증 구간 백테스트를 다시 실행하지 않았다.

| 계열 | 판정 | 근거 |
